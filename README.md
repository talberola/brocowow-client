# Brocowow addon pack

A curated World of Warcraft **3.3.5a** interface pack for a small private
group. Everything is preconfigured — unzip it and play.

## Install

1. Download `BrocowowAddons.zip` from
   [Releases](../../releases/latest).
2. Unzip it and put the folders inside your WoW `Interface/AddOns` folder.
3. Fully restart the game if it is running.
4. At the character screen, click **AddOns** and tick
   **Load out of date AddOns**.

On your first login the included `BrocowowDefaults` addon sets sensible
defaults for you once, then never touches your settings again. Change anything
you like afterwards — it sticks. `/brocoreset` re-applies the defaults if you
ever want them back.

## What's inside

| Addon | What it does |
|---|---|
| Deadly Boss Mods | Boss timers and warnings |
| AtlasLoot Enhanced | Browse loot tables |
| Bartender4 | Action bars |
| Bagnon | One-bag inventory |
| Details! | Damage meter |
| Quartz | Cast bar |
| NotPlater | Threat-aware nameplates |
| BrocowowDefaults | One-time first-login setup |
